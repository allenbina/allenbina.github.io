Started as a media PC when I was 23. Grew through every phase of self-hosting — PHP and MySQL on an Atom nettop, SSH tunnels for remote access, Docker, and eventually k3s with ArgoCD, Longhorn storage, and automated Velero backups.

Currently running 30+ services across a three-node cluster with etcd HA, Cloudflare tunnels for external access, and a Kestra-based alert triage agent.
